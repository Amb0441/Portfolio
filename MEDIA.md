# Responsive Breakpoints

## Desktop (> 1024px)
- Full two-column grids (Hero, About, Contact)
- Max content width: 960px
- Hero circle: 280px
- Section gap: 8rem

## Tablet (768px — 1024px)
- Same grid layout, tighter gaps
- Hero circle: 220px
- Section gap: 5rem

## Mobile (< 768px)
- All grids stack to single column
- Hero: image on top, text below
- Section padding: 1.25rem
- Hero circle: 180px
- Project cards: links wrap below
- Experience/Education: period/year on its own row
- Section gap: 5rem
